🇫🇷 OtaimFlux : mode d’emploi en 5 étapes

OtaimFlux est un outil gratuit pour monter et diffuser des films à séquences variables : à chaque passage, il tire au hasard une variante pour chaque séquence (sans en répéter avant d’avoir tout joué), puis boucle sans fin. Vos vidéos restent sur votre propre serveur.

  1. Préparez vos vidéos. Exportez chaque variante en MP4 (H.264) avec l’option « Web Optimized » (HandBrake) ou « Fast Start » (Final Cut, Compressor) : sans elle, la lecture peut sembler « cassée ». Donnez-leur des noms simples, sans accents, espaces ni apostrophes, et déposez-les dans un même dossier de votre hébergement.
  2. Renseignez le générateur. Étape ① : le titre et le nombre de séquences. Étape ② : pour chaque séquence, collez les adresses de ses variantes (une par ligne) ou, après avoir indiqué l’adresse de base du dossier, importez ou glissez les fichiers eux-mêmes (seul leur nom compte). Tout le reste (règles d’exclusion, sons, timing, miniature, étape ④) est facultatif et expliqué dans le générateur.
  3. Vérifiez et prévisualisez. « Vérifier les vidéos » teste chaque adresse. L’étape ⑤ résume le film (nombre de films possibles, liste « Prêt à publier ») et « Prévisualiser le film » le joue sans quitter le générateur.
  4. Cliquez sur « Générer les codes ». Deux codes apparaissent dans deux onglets : 1 · Code pour votre page et 2 · Page iframe (HTML).
  5. Publiez.
    • Code 1 : collez-le à l’endroit de votre page où le film doit apparaître, dans un bloc « HTML personnalisé » (WordPress) ou l’équivalent de votre outil de site (Wix, Squarespace, Webflow, Joomla…).
    • Code 2 : copiez-le dans un éditeur de texte brut (Bloc-notes, TextEdit en mode « texte brut » ; pas Word), enregistrez-le en .html sous le nom prévu à l’étape ④, puis déposez-le sur votre hébergement à cette adresse. C’est la page que propose le bouton « Intégrer » du player. Après chaque remplacement de ce fichier, ajoutez ?v=2, puis ?v=3… à l’adresse de l’iframe pour que les navigateurs n’affichent pas l’ancienne version.

Retrouver un film plus tard

Le générateur garde en mémoire, dans votre navigateur, le film en cours (un seul, sur cet ordinateur) ; « Nouveau film » l’efface. Pour reprendre un film déjà publié, même depuis un autre ordinateur : ouvrez « Reprendre un film déjà généré » et collez le code de votre page (ou le fichier .html du player). Modifiez, cliquez de nouveau sur « Générer les codes », remplacez l’ancien code et redéposez le fichier .html. Conservez le code de chaque film : c’est votre sauvegarde.

En cas de problème

  • Zone noire, ou rien ne se lance : lancez « Vérifier les vidéos » ; le plus souvent, une adresse est incorrecte.
  • Le film démarre lentement : les vidéos ne sont pas optimisées pour le web (étape 1).
  • Le code s’affiche en clair sur la page : il n’a pas été collé dans un bloc de code HTML.
  • Le fichier .html s’ouvre comme une page : c’est normal. Pour le copier, ouvrez-le avec un éditeur de texte (clic droit, « Ouvrir avec »).

🇬🇧 OtaimFlux: user guide in 5 steps

OtaimFlux is a free tool for editing and publishing variable-sequence films: each time round, it picks a random variant for every sequence (never repeating one until all the others have played), then loops endlessly. Your videos stay on your own server.

  1. Prepare your videos. Export each variant as MP4 (H.264) with “Web Optimized” (HandBrake) or “Fast Start” (Final Cut, Compressor) switched on: without it, playback can seem broken. Give them simple names, with no accents, spaces or apostrophes, and upload them to one folder on your hosting.
  2. Fill in the generator. Step ①: the title and the number of sequences. Step ②: for each sequence, paste the addresses of its variants (one per line) or, once you have entered the folder’s base address, import or drag the files themselves (only their name counts). Everything else (exclusion rules, sounds, timing, thumbnail, step ④) is optional and explained in the generator.
  3. Check and preview. “Check the videos” tests every address. Step ⑤ summarises the film (number of possible films, “Ready to publish” checklist) and “Preview the film” plays it without leaving the generator.
  4. Click “Generate the codes”. Two codes appear in two tabs: 1 · Code for your page and 2 · Iframe page (HTML).
  5. Publish.
    • Code 1: paste it where the film should appear on your page, in a “Custom HTML” block (WordPress) or the equivalent in your site builder (Wix, Squarespace, Webflow, Joomla…).
    • Code 2: copy it into a plain-text editor (Notepad, or TextEdit in “plain text” mode; not Word), save it as .html under the name planned in step ④, then upload it to your hosting at that address. This is the page offered by the player’s “Embed” button. Each time you replace this file, add ?v=2, then ?v=3… to the iframe address so that browsers do not show the old version.

Find a film again later

The generator keeps the film in progress in your browser’s memory (just one, on this computer); “New film” clears it. To reopen a film that is already published, even from another computer: open “Reopen a film you already generated” and paste your page’s code (or the player’s .html file). Edit, click “Generate the codes” again, replace the old code and upload the .html file again. Keep the code of each film: it is your backup.

Troubleshooting

  • Black area, or nothing plays: run “Check the videos”; most often an address is wrong.
  • The film starts slowly: the videos are not optimised for the web (step 1).
  • The code shows up as text on the page: it was not pasted into an HTML code block.
  • The .html file opens as a web page: that is normal. To copy it, open it with a text editor (right-click, “Open with”).
